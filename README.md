# Problema de Josephus

Repositório desenvolvido para a resolução do clássico **Problema de Josephus** (Josephus Problem), um problema teórico de matemática e ciência da computação frequentemente utilizado para estudar estruturas de dados lineares, como listas encadeadas ou filas/pilhas, e algoritmos recursivos ou iterativos.

---

## Sobre o Problema

O Problema de Josephus consiste em um grupo de pessoas dispostas em um círculo. Começando a contagem a partir de uma determinada pessoa, elimina-se a cada $k$-ésima pessoa do círculo. O processo se repete com as pessoas restantes até que reste apenas uma única pessoa, que é declarada a sobrevivente.
